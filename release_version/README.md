# Dual Encoder Attribution tool

Text-Text / Text-Image Attribution Visualization

## Quickstart

If you are using Windows, run the `run.bat` file, on Linux or macOS, use `run.sh`.<br>
These scripts will create a python virtual environment, instal lthe pip dependencies listed in `app\requirements.txt`, download a spacy package for POS tagging before running the backend alongside the frontend. Finally the browser window should open the UI of the visualization tool.
